# PHATSO Landing Page

Static landing page for GitHub Pages.

## Local preview

Open `index.html` in a browser, or run a local server from this folder:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## GitHub Pages

This repository is set up to host the PHATSO landing page. In GitHub, enable Pages from the repository settings and choose the `main` branch with the root folder.
